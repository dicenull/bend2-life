# ライフゲーム / Bend 2

Notionの「ライフゲーム」案を、Bend 2で動く小さなプロトタイプにしたものです。盤面は32×32で、1行の生死を32ビット整数1個に詰めています。世代の計算と8近傍の集計はBend 2、盤面の描画・タップ操作・タイマーはJavaScriptです。

## 遊ぶ

`index.html` をブラウザで開きます。サーバー、Bendのインストール、ネット接続は不要です。はじめはグライダーが置いてあります。「再生」か「1世代進める」を押してください。タップでセルを反転し、ドラッグで連続して配置・消去できます。四辺の外は死セルとして扱い、反対側にはつながりません。

## ソースと検証

- `main.bend`: セルの遷移とビットボード上の1行の更新。
- `LAWS.bend`: 生存・誕生・過疎・過密の仕様。近傍数0・1・2・3・4以上を網羅。
- `PROOF.bend`: セル遷移の証明。盤面上で近傍を数える処理やUIは証明の対象外。
- `test.mjs`: コンパイル済みBendコードと素朴な参照実装を比較。全512通りの局所配置、乱数で作った盤面の更新500回、既知パターン、端の非接続を確認。
- `browser.template.html` と `build.mjs`: UIテンプレートと、コンパイル結果を単独で開けるHTMLにまとめるスクリプト。

[Bend 2](https://github.com/bendlang/bend) 2.0.40（コミット `6180be5b21c4af6895395b27ad3cde026909364e`）、Node.jsで再現できます。

```sh
bend PROOF.bend
bend PROOF.bend --verdict   # 独立したBendTTカーネル。Lean 4.34.0が必要
node build.mjs              # life.mjsとindex.htmlを生成
node test.mjs
```

通常のチェックとBendTTカーネルの再検査は、どちらも `ALL PROOFS CHECK`。ルールを「常にそのまま」「近傍2でも誕生」に変更すると証明が通らず、盤面の左右をつなぐ変更はテストで落ちることも確認しました。
