# ライフゲーム / Bend 2

Notionの「ライフゲーム」案を、Bend 2で動く小さなプロトタイプにしたものです。盤面は64×40、96×56（初期値）、128×72から選べます。横32セルごとに1個の32ビット整数に詰め、境界のセルも隣の区画を参照します。近傍判定とセル遷移はBend 2、盤面の描画・タップ操作・タイマーはJavaScriptです。

## 遊ぶ

`index.html` をブラウザで開きます。サーバー、Bendのインストール、ネット接続は不要です。はじめはグライダーが置いてあります。「再生」か「1世代進める」を押してください。盤面にフォーカスがあるときは、Spaceで再生・停止、→で停止して1世代進めます。Tabで移動したボタンや選択欄は、標準のキー操作を保ちます。タップでセルを反転し、ドラッグで連続して配置・消去できます。「拡大」でセルを置きやすくし、「移動」モードで盤面をドラッグできます。「全体表示」で全体に戻ります。盤面サイズを変更すると左上を基準に重なる範囲を保持します。現在選んでいるサイズが盤面の範囲です。盤面の外は常に死セルで、外で誕生したり反対側につながったりはしません。盤面を広げたとき、増えた部分は死セルから始まります。

## Macアプリ版（Bend 2）

ブラウザ版とは別に、Macで起動する版を用意しています。盤面、操作、入力判定、描画はすべてBendで、アプリ実行にJavaScriptやブラウザは使いません。ビルドには上記のBend 2とXcodeのCommand Line Toolsが必要です。シェルスクリプトはコンパイルとMacアプリの梱包だけを行います。

```sh
./build-native.sh
open '.build/Bend 2 Life.app'
node native-test.mjs
```

上の7ボタンは左から再生・停止、1世代進む、消去、グライダー配置、サイズ切り替え、縮小、拡大。拡大率は1x・2x・3x・4xで、盤面の中央を軸に切り替えます。現在の倍率は−と＋の間に表示します。**Space**で再生・停止、**→**で1世代進む、**C**で消去、**G/B/O**でグライダー・ブリンカー・ブロック、**1/2/3**でサイズを選べます。クリックやドラッグでセルを編集できます。パンとランダム配置はブラウザ版のみです。

| 層 | ファイル | 担当 |
| --- | --- | --- |
| ルール・証明 | `main.bend` / `LAWS.bend` / `PROOF.bend` | Conwayルールと有限盤面の更新。ブラウザ版と共有 |
| 盤面 | `native-board.bend` | ビット盤面の保存、編集、サイズ変更、世代更新 |
| 操作 | `native-state.bend` / `native-layout.bend` | 純粋な状態変更と、描画・入力が共有する座標 |
| 表示 | `native-view.bend` | 状態からBendの `Image` を作る |
| OS | `native.bend` | ウィンドウ、イベント受け渡し、時刻、再描画のキャッシュ |

`bend PROOF.bend` は共通ルールと境界を証明します。Mac版の基盤データ構造、入力や描画の配線は証明の対象にせず、`native-test.mjs` で盤面・操作・ブラウザ版との一致を確認します。

## ソースと検証

[証明とテストの分け方](docs/proof-vs-tests.md)に、ルール・盤面更新・UIで確認方法をどう分けるかをまとめています。

- `main.bend`: セルの遷移とビットボード上の32セルと区画境界の更新。
- `board.mjs`: 盤面サイズとビットボードの管理。9区画分の候補値と四辺までの距離をBendに渡す。盤面外の候補値を無視する判断はBend側で行う。
- `LAWS.bend`: セル遷移の5法則と、32ビット区画の各セルと、隣接する9区画から計算した更新結果全体が、8近傍の参照計算に一致する法則。
- `PROOF.bend`: セル遷移、全32ビットの一致、隣接区画からの境界ビット抽出の証明。JavaScript側の区画選択とUIは証明の対象外。
- `proof-patterns.bend`: 自然数の帰納法と、2つの等式を1つにまとめる再利用可能な定義。[使い方と別の例](docs/proof-patterns.md)。
- `pattern-spec.bend`: 継ぎ目をまたぐ静止パターンと周期2の証明に使う、固定サイズの盤面。
- `test.mjs`: コンパイル済みBendコードと素朴な参照実装を比較。区画境界3箇所の左右で各512通りの局所配置、乱数で作った盤面の更新500回、既知パターン、サイズ変更、端の非接続を確認。
- `browser.template.html` と `build.mjs`: UIテンプレートと、コンパイル結果を単独で開けるHTMLにまとめるスクリプト。

[Bend 2](https://github.com/bendlang/bend) 2.0.40（コミット `6180be5b21c4af6895395b27ad3cde026909364e`）、Node.jsで再現できます。

```sh
bend PROOF.bend
bend PROOF.bend --verdict   # 独立したBendTTカーネル。Lean 4.34.0が必要
node build.mjs              # life.mjsとindex.htmlを生成
node test.mjs
```

セル遷移のルールは初版と同じです。区画境界や盤面サイズの処理は `node test.mjs` で確認できます。
