# 盤面の端をどう扱うか

[LAWS.bend](../LAWS.bend) の `bounded_word_matches_dead_exterior` と `wrapped_word_matches_opposite_edges` は、同じConwayのセル更新を異なる境界条件で使う。

| 位置 | 盤面外は死 | 上下左右がつながる（トーラス） |
|---|---|---|
| 盤面内の32セル区画の継ぎ目 | 隣の区画を読む | 同じ |
| 盤面の端 | 外側を死セルとして数える | 反対側の端を読む |
| 盤面の角 | 片方でも盤面外なら死 | 2軸とも反対側に回り込む |

横64セル・縦5行の盤面で、列 `63, 0, 1` の3セルを行2に置く。列番号と行番号は0始まり。

| 条件 | 1世代後 |
|---|---|
| 盤面外は死 | 全滅。左端の2セルと右端の1セルはつながらない。 |
| トーラス | 列0の行 `1, 2, 3` が生き、縦のブリンカーになる。 |

[比較例](../examples/edge-comparison.bend)では、このブリンカーに加え、上下端をまたぐブリンカーと、斜め向かいの角にあるセルが誕生に寄与する例を確認する。

```sh
bend PROOF.bend
bend examples/edge-comparison.bend
```

トーラス側のLAWは、横を32セル区画単位とする矩形で、更新位置と両端までの距離を入力に取る。座標選択の実装を端・内部・区画や行が1つだけの場合に分けて参照仕様と照合し、32セルを更新する既存の証明を再利用する。盤面の寸法と距離を対応させるのは呼び出し側の責任。Web版は起動時に端がつながる。「端をつなぐ」で境界条件を切り替えられる。「端のブリンカー」を配置すると同じ初期状態で比較できる。Mac版は「盤面外は死」で動く。
